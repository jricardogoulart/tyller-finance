# PP Neue Montreal - Font Setup Directory

Paste the font files for **PP Neue Montreal** / **Neue Montreal** in this folder.

## Recommended Filenames
To match the `@font-face` declarations pre-configured in `front/src/index.css`, please name your files exactly as follows:

- **Regular / Book (Weight 400)**: `PPNeueMontreal-Regular.woff2` (or `.woff`, `.ttf`)
- **Medium (Weight 500)**: `PPNeueMontreal-Medium.woff2` (or `.woff`, `.ttf`)
- **Bold (Weight 700)**: `PPNeueMontreal-Bold.woff2` (or `.woff`, `.ttf`)
- **Light (Weight 300)**: `PPNeueMontreal-Light.woff2` (or `.woff`, `.ttf`)

## Format Support
Web Open Font Format 2 (`.woff2`) is highly recommended for production web applications due to its superior compression rate and speed.
